# Juguetes y Deporte Cart

Compara precios de juguetes, zapatillas, ropa deportiva y bicis en Cebra, Kinderland, Frávega, Dexter, Moov, Stock Center, Sporting y Grid.

- `api/vtex.js`: búsqueda por código de barras, nombre o modelo (VTEX, Shopify y Salesforce).
- `lib/tiendas2.js`: lectores de Kinderland (Shopify) y del grupo Dexter (Salesforce).
- `supabase/jyd.sql`: tablas de la app (correr una vez en Supabase).
